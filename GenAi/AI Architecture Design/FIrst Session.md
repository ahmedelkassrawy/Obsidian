C4 Framework
- **Level 1: System Context Diagram**
    - **What it shows:** The big picture—the software system you are building, its users (people), and any external software systems or third-party services it interacts with.
    - **Audience:** Both technical and non-technical stakeholders (managers, product owners, executives)
- **Level 2: Container Diagram**
    - **What it shows:** The high-level technology building blocks inside the system—such as web applications, mobile apps, databases, microservices, or message queues—along with their communication paths and technology choices. _(Note: A "container" here means an executable application or data store, not a Docker container)._
    - **Audience:** Architects and developers
- **Level 3: Component Diagram**
    - **What it shows:** The internal modules, controllers, repositories, or functional building blocks inside an individual container.
    - **Audience:** Software engineers working on specific services
- **Level 4: Code Diagram**
    - **What it shows:** Implementation details such as classes, interfaces, or database schemas (often auto-generated by IDEs).
    - **Audience:** Developers (usually optional or rarely maintained manually because code changes too fast)
