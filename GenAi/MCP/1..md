## Which SDK / class (v1 vs v2)

The class got renamed between versions, and this is the #1 source of the "cannot import name" error.

- **v1** (`mcp` 1.x): `from mcp.server.fastmcp import FastMCP` → `mcp = FastMCP("name")`. No `version=` arg.
- **v2** (`mcp` 2.x): `from mcp.server import MCPServer` → `mcp = MCPServer("name")`. Takes `version=` and `log_level=`.

There is **no** class called `MCPServer` in v1 and no `FastMCP` needed in v2. Check your installed version first: `python -c "import mcp; print(mcp.__version__)"`. Everything below is v2 (what I run).

## The finished server (full working code)

```python
import json
import logging
from mcp.server import MCPServer          # v2. (v1: from mcp.server.fastmcp import FastMCP)
from pydantic import BaseModel

logger = logging.getLogger(__name__)

TASK_FILE = "tasks.json"
tasks = []
max_id = 0

class Task(BaseModel):
    id: int
    text: str
    done: bool = False

mcp = MCPServer("Personal Task")           # add log_level="DEBUG" to see logger lines

def save_tasks():
    """Save the current list of tasks to a file."""
    try:
        with open(TASK_FILE, "w") as f:
            json.dump([task.model_dump() for task in tasks], f)
            logger.info(f"Tasks saved to {TASK_FILE}")
    except Exception as e:
        logger.error(f"Error saving tasks: {e}")

def load_tasks():
    """Load the list of tasks from a file."""
    global tasks, max_id
    try:
        with open(TASK_FILE, "r") as f:
            tasks = [Task(**task) for task in json.load(f)]
        for task in tasks:
            if task.id > max_id:
                max_id = task.id
        logger.info(f"Loaded {len(tasks)} tasks from {TASK_FILE}")
    except FileNotFoundError:
        tasks = []
        logger.info("No task file found. Starting empty.")

@mcp.tool("add-task")
def add_task(text: str):
    """Add a new task to the list of tasks."""
    global nextid
    task = Task(id=nextid, text=text, done=False)
    tasks.append(task)
    nextid += 1
    save_tasks()
    return task

@mcp.tool("list-tasks")
def list_tasks():
    """List all tasks."""
    return tasks

@mcp.tool("complete-task")
def complete_task(task_id: int):
    """Complete a task by its ID."""
    for task in tasks:
        if task.id == task_id:
            task.done = True
            save_tasks()
            return task
    return None

@mcp.tool("edit-task")
def edit_task(task_id: int, new_text: str):
    """Edit a task by its ID."""
    for task in tasks:
        if task.id == task_id:
            task.text = new_text
            save_tasks()
            return task
    return None

@mcp.tool("clear-completed-tasks")
def clear_completed_tasks():
    """Clear all completed tasks."""
    global tasks
    before = len(tasks)
    tasks = [task for task in tasks if not task.done]
    save_tasks()
    return f"Cleared {before - len(tasks)} completed tasks."

load_tasks()                 # runs at startup (import time)
nextid = max_id + 1          # must come AFTER load_tasks()
```

## How to build it, step by step

1. **Create the server object.** Import the class for your version, then `mcp = MCPServer("name")`.
2. **Define the data shape** with a Pydantic `BaseModel` (`Task`). Type hints become the tool schema for free.
3. **Add a tool** = a normal function with `@mcp.tool("tool-name")`. The docstring is the tool description the model reads. Type hints on the args become the input schema. No manual JSON schema.
4. **Return what you want the model to see.** The return value is the only thing the model gets. Logs do NOT reach the model.
5. **Add persistence:** `load_tasks()` at startup, `save_tasks()` after every change.
6. **Run it** (see run section). Test each tool in the Inspector, then restart and list again to prove persistence.

## Things to do so you don't get errors (the traps I actually hit)

- **`global` for any module variable you REASSIGN inside a function.** If a function does `tasks = ...` or `max_id = ...`, it needs `global tasks, max_id` at the top, or you get `UnboundLocalError`. You do NOT need `global` if you only read it or only mutate it in place (`.append`, `task.done = True`).
- **Never remove from a list while looping over it.** `for t in tasks: tasks.remove(t)` skips items. Rebuild instead: `tasks = [t for t in tasks if not t.done]`.
- **Return inside the loop when you find the match.** Looping and returning after the loop gives you the *last* item, not the matched one, and crashes with `NameError` if the list is empty. See `complete-task` / `edit-task` above.
- **Startup = import time.** A bare call like `load_tasks()` at the left margin (not inside a `def`) runs when the file is imported, which is startup. It must sit at the BOTTOM, after the function is defined and after `tasks`/`max_id` exist.
- **Order the id setup right.** `nextid = max_id + 1` must run AFTER `load_tasks()` so it sees loaded tasks. And don't add `+1` in two places (once here and again inside `add-task`) or your first id gets skipped. Rule: assign `id=nextid` first, THEN `nextid += 1`.
- **Never `print()` in a stdio server.** stdout is the protocol wire; printing corrupts it. Use `logging` (goes to stderr). Split: `logger.*` = for you in the terminal, `return` = for the model.
- **Logs are silent by default.** Default level is WARNING, so `logger.info` shows nothing. Pass `log_level="DEBUG"` to `MCPServer(...)` to see them.
- **Pydantic v2:** use `task.model_dump()`, not the deprecated `task.dict()`.

## Running it (Windows + base conda, no venv)

Confirm the CLI is installed once: `pip install "mcp[cli]"` (this gives the `mcp` command / `typer`).

- **Just run the server** (no UI): `mcp run D:\me\teach\mcp\server.py`
- **Run with the Inspector UI:** `npx @modelcontextprotocol/inspector mcp run D:\me\teach\mcp\server.py`

**Avoid `uv run mcp dev ...` on a base-conda setup.** `mcp dev` builds a throwaway `uv run --with mcp` environment that installs plain `mcp` WITHOUT the `[cli]` extra, so it fails with `Error: typer is required`. Launching the Inspector directly with `npx ... mcp run` uses your base-conda `mcp` (which has typer) and sidesteps the whole thing.
